## 与本仓库增强版（V3 / V2）的区别

| 能力 | 原始版 spark.py | V2 增强版 ewt_brush_v2.py | **V3 正式版 ewt_brush_v3.py** ⭐ |
|---|---|---|---|
| 登录方式 | 仅接受已有 token | 账号密码自动登录（AES+oauth）| 同 V2 + 登录签名头（降风控）|
| 扫描 | 手动发现作业/课时 | 自动扫描全部未完成课时 | 同 V2，配置无上限 |
| 并行 | 单课竞态爆发（~5x）| 外层 N 路并行 + 内层竞态爆发 | 同 V2，进度延迟复核防重刷 |
| 多实例 | 不支持 | 支持分片（offset/limit/phase-offset）| 同 V2，easy 自动分片 + 进度条面板 |
| token 续期 | 无 | 自动续期（最多 3 次）| 同 V2 |
| WAF 风控 | 基础限速 | 自动冷却 120s 重试（最多 2 次）| 同 V2 |
| 看课检测 | 无 | 三重兜底机制（弹题/置过/重刷）| 同 V2 + 过课检测参数优化、判定阈值 0.8 |
| 自动验证 | 无 | 刷完自动重扫 + 失败补刷 | 同 V2 |
| FM/板报直写 | 无 | 不处理 | ✅ updateMission 直写 100% |
| clog 补发 | 无 | 无 | ✅ 补发播放日志提高完成率 |
| Windows 兼容 | 可能乱码 | 可能乱码 | ✅ UTF-8 加固无乱码 |
